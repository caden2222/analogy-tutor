The actual flow

Query + Keys→Scores→Softmax weights→Weighted Values→Output

Scores come from scaled query–key dot products. Softmax makes weights; each weight scales its value, then the contributions are summed. Values are information, never scores.

The story has a limit: real queries, keys and values are vectors, not book labels. Attention combines information; it does not simply pick one winning book.
